# Homelab infrastructure

This repository contains Flux-managed Kubernetes applications and infrastructure,
a kind-based development cluster bootstrap, and the source for the Django/Vite
Campfire application. It is intended for two clusters: `dev` and `homelab`.
The development cluster is configured; the homelab cluster is not yet bootstrapped.

Start with the [documentation index](docs/README.md), especially the
[cluster architecture](docs/architecture.md),
[component guide](docs/adding-components.md), and
[secrets guide](docs/secrets.md). Repository-wide instructions for AI agents
are in [AGENTS.md](AGENTS.md).
