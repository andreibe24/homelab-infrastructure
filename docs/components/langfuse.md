# Langfuse

[Langfuse](https://langfuse.com) is an open-source LLM observability platform
(traces, token usage and cost, prompt management, evaluations).
`infrastructure/components/langfuse/` deploys it with the upstream Helm chart
(Postgres, Valkey and SeaweedFS S3 bundled), plus:

- a single-node ClickHouse StatefulSet (`clickhouse.statefulset.yaml`) instead of
  the chart's operator-based ClickHouse, which would need another operator;
- an OpenTelemetry Collector that receives OTLP/gRPC from agentgateway and
  forwards to Langfuse's OTLP/HTTP endpoint with Basic authentication;
- a `ReferenceGrant` allowing the agentgateway tracing policy to reach the
  collector, and an HTTPRoute for the UI.

UI: `https://langfuse.localhost` (include the gateway HTTPS port if needed).
Sign-up is disabled; headless initialisation creates the `admin@homelab.local`
user, the `homelab` organisation and the `llm-gateway` project.

## Secret

`clusters/dev/init-manifests/secrets/langfuse.secret.yaml` (SOPS, reflected into
`langfuse`) holds the salt, encryption and NextAuth keys, the ClickHouse password,
the project API key pair, the admin password and the collector's
`otel-authorization` header (`Basic base64(public:secret)`). Retrieve the admin
password with `sops decrypt`; keep it out of logs. If you rotate the project
keys, update `otel-authorization` to match. Postgres, Valkey and S3 credentials
are generated by the chart and retained by Helm.

## Usage

Requests through agentgateway appear as traces with model, provider, token usage
and latency. Try it with the Ollama route described in
[Agentgateway](agentgateway.md#local-models-ollama).

## Notes

- Sizing is small (ClickHouse 10Gi, Postgres 5Gi); adjust the HelmRelease values
  and StatefulSet for real use. Not validated on the `homelab` cluster, where
  shared infrastructure is suspended.
- Chart and ClickHouse versions are Renovate-managed; the ClickHouse tag follows
  the chart default and should be kept aligned on upgrades.
